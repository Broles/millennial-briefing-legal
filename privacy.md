# Datenschutzerklärung / Privacy Policy

Stand: 1. Oktober 2026

## Deutsch

### Wer verantwortlich ist
Millennial Briefing ist ein privates Projekt. Kontakt für alle Datenschutzfragen: alexander.shapovalenko@googlemail.com

### Was die Anwendung tut
Millennial Briefing ist ein internes Werkzeug. Es erstellt Videos aus öffentlichen Nachrichtenmeldungen und lädt sie über die YouTube Data API (YouTube API Services) auf den eigenen YouTube-Kanal „Millennial Briefing“ hoch. Dazu bittet die Anwendung um den Zugriff `https://www.googleapis.com/auth/youtube.upload`, ausschließlich für das Google-Konto des Betreibers.

### Welche Daten verarbeitet werden
- **Keine Daten von Besuchern oder Nutzern.** Die Anwendung wird nur vom Betreiber verwendet. Sie erhebt, speichert und verkauft keine personenbezogenen Daten Dritter.
- **Zugangsdaten des Betreibers:** Das von Google ausgestellte Zugriffstoken (Refresh-Token) wird ausschließlich als verschlüsseltes Secret in einem privaten GitHub-Repository des Betreibers gespeichert und nur verwendet, um Videos auf den eigenen Kanal hochzuladen.
- **Inhalte:** Hochgeladen werden nur selbst erstellte Videos, Titel und Beschreibungen. Es werden keine Daten aus dem YouTube-Konto gelesen, ausgewertet oder an Dritte weitergegeben.

### Weitergabe und Nutzung der Google-Daten
Die Nutzung und Weitergabe von Informationen, die aus Google-APIs stammen, erfolgt in Übereinstimmung mit der [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Es findet keine Weitergabe an Dritte, keine Werbenutzung und keine Nutzung für das Training von KI-Modellen statt.

### YouTube
Es gelten außerdem die [YouTube-Nutzungsbedingungen](https://www.youtube.com/t/terms) und die [Datenschutzerklärung von Google](https://policies.google.com/privacy).

### Zugriff widerrufen und Löschung
Den Zugriff kannst du jederzeit unter [myaccount.google.com/permissions](https://myaccount.google.com/permissions) widerrufen. Auf Anfrage per E-Mail werden gespeicherte Zugangsdaten gelöscht.

### Diese Webseite
Diese Seite wird über GitHub Pages bereitgestellt. GitHub kann beim Aufruf technische Daten wie die IP-Adresse verarbeiten, siehe die [Datenschutzerklärung von GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Der Betreiber erhebt selbst keine Zugriffsdaten.

## English

Millennial Briefing is a private tool operated by one person. It creates videos from public news items and uploads them through the YouTube Data API (YouTube API Services) to the operator's own YouTube channel "Millennial Briefing". It requests the scope `https://www.googleapis.com/auth/youtube.upload` for the operator's own Google account only.

**Data.** The application does not collect, store, share or sell personal data of visitors or other users. The only credential stored is the operator's Google refresh token, kept as an encrypted secret in a private repository and used solely to upload videos to the operator's own channel. No data is read from the YouTube account beyond the upload itself.

**Google user data.** Use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. No data is disclosed to third parties, used for advertising, or used to train AI models.

**YouTube.** The [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy) also apply.

**Revoking access and deletion.** Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Stored credentials are deleted on request.
